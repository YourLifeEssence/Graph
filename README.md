# Graph Algorithms (C++)

Набор алгоритмов для анализа ориентированных и неориентированных графов. Граф загружается из текстового файла, после чего выбранный алгоритм выводит результат в консоль.

## Возможности

- компоненты связности (DFS) и слабая связность орграфа;
- мосты и точки сочленения, включая линейную версию `O(V + E)`;
- остовные деревья (DFS/BFS) и минимальное остовное дерево;
- проверка двудольности и максимальное паросочетание (алгоритм Куна);
- компоненты сильной связности;
- характеристики графа по кратчайшим расстояниям: степени, эксцентриситеты, диаметр, радиус, центральные и периферийные вершины;
- восстановление кратчайших путей, Беллман—Форд—Мур и A*;
- максимальный поток (Форд—Фалкерсон);
- муравьиный алгоритм поиска гамильтонова цикла, включая многопоточную реализацию.

| Файл | Назначение |

## Требования

- Windows (используется `windows.h`);
- компилятор с поддержкой C++17;
- CMake 3.28+ при сборке через CMake.

Внешние библиотеки не требуются.

## Сборка и запуск

```powershell
cmake -S . -B build
cmake --build build --config Release
.\build\Release\Graph.exe
```

Или напрямую:

```powershell
g++ -std=c++17 -O2 main.cpp -o graph.exe
.\graph.exe
```

Перед запуском измените в `main.cpp` путь к входному файлу, тип графа и вызываемую задачу:

```cpp
const std::string path = "data/flow.txt";
MatrixGraph graph(path);
task14(&graph);
```

Нумерация соответствует функциям `task1`–`task14` и реализации в `task19.h`.

## Форматы входных данных

Первая строка содержит число вершин `V`. Нумерация вершин начинается с **1**.

### Матрица смежности

Следующие `V` строк содержат `V` чисел. Ноль означает отсутствие ребра, ненулевое значение — наличие ребра или его вес.

```text
4
0 1 0 7
1 0 1 0
0 1 0 2
7 0 2 0
```

### Список смежности

Следующие `V` строк перечисляют соседей. Для взвешенного графа используется запись `вершина:вес`.

```text
4
2 4:7
1 3
2 4:2
1:7 3:2
```

### Список рёбер

Каждая строка после первой задаёт ребро как `откуда куда` или `откуда куда вес`.

```text
4
1 2
2 3 5
3 4
4 1 7
```

Для неориентированного графа обратные рёбра должны присутствовать в данных.

## Примечания

- `main.cpp` содержит пример запуска одной задачи, а не универсальный CLI.
- Для задач потоков нужны ориентированные рёбра с неотрицательными пропускными способностями; исток и сток определяются автоматически.
- Муравьиный алгоритм вероятностный, поэтому результаты могут отличаться между запусками.
- Большинство функций выводит результат непосредственно в стандартный поток.
